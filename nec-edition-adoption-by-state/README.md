# Which National Electrical Code edition each US state enforces: adoption status, effective dates and amendments, from the state boards themselves

The NEC edition currently in force in each US state, with the effective date, the adopting authority, whether state amendments apply, and any announced transition to a newer edition. The spread is real and moving: Minnesota's Board of Electricity put the 2026 NEC in force on Aug. 17, 2026 (permits filed before that date still follow the 2023 NEC); Oregon's 2023 Oregon Electrical Specialty Code, based on the 2023 NEC, took effect Oct. 1, 2023 with a published table of amendments, and the 2026 OESC is in adoption; Washington's WAC 296-46B-010 carries the 2023 NEC with the 2026 edition already written in for Dec. 31, 2026; Nebraska has been on the 2023 NEC since Aug. 1, 2024. Answers 'which NEC edition is in effect in my state?', 'which states have adopted the 2026 NEC?', 'does my state amend the NEC or adopt it unamended?', 'when does the new electrical code take effect for permits?'. Caveat: local jurisdictions (AHJs) may enforce a different edition; this asset records statewide adoption only. Which edition is in force changes month to month, which is why every record carries the date its source states and a verbatim quote — a static tracker published two weeks before Minnesota's cutover was wrong two weeks later, and so was an earlier version of this asset.
