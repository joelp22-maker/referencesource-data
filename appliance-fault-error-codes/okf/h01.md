**Brand:** Bosch

**Appliance type:** Dishwasher

**Error code:** H01

**Meaning:** This is not an actual error code, but an indication that the start-up timer menu has been accessed to delay the start of the cycle, with H01 for a 1-hour delay and h02 for a 2-hour delay, and so on.

> H01 for a 1-hour delay and h02 for a 2-hour delay, and so on. To delete timer programming, press the [4] + or &ndash; button until h:00 is displayed on the digital display. See more Additional Bosch Dishwasher
