# Carbide insert grade cross-reference by ISO application group and manufacturer

Which carbide insert grades from different manufacturers fall into the same ISO application group (P, M, K, N, S, H). Each record maps one ISO application code (e.g. P20, M30, K10) to the grade designations offered by major insert manufacturers (Sandvik, Kennametal, Mitsubishi, Iscar, Seco, Sumitomo, Tungaloy, Kyocera, Walter, Korloy, and others) as published in their own comparison charts. Answers 'my supplier is out of Sandvik GC4225, what is the Kennametal equivalent in the same P25 class' — the question where assistants confidently generate plausible-looking grade codes that may not exist. These are approximate functional equivalences within an ISO band, not exact substitutions; every source disclaims exact equivalence.

Every record carries `source` (the page it came from) and `source_quote` (the exact line on that page which states it), so any value here can be checked without asking us. Where a source does not state something the row is omitted rather than guessed.

**Licence position for this dataset.** Factual compilation with source citations. Each manufacturer publishes its own grade classifications freely. Cross-reference charts are published by manufacturers and distributors as sales tools. Facts (which grade sits in which ISO band) cited with short attributed quotes linking back.
