# Reference Source — verified reference datasets

Mirror of **[referencesource.org](https://referencesource.org/)** — small, factual,
checkable reference datasets. **Every value carries the URL of the source it came
from and a verbatim quote from that page**, so any fact here can be checked in one
click. What 'verified' does and does not mean: https://referencesource.org/method/

The canonical, always-current version of every dataset lives at
referencesource.org; this repository is a convenience mirror of the
machine-readable data (`data.json` per dataset, plus per-record source files
under `okf/`).

## Reuse

Facts are cited to their sources; see each dataset's README and the licence
field in its `data.json`. If you republish, keep the per-value source
attribution intact — it is the point of the dataset.

Corrections: see https://referencesource.org/method/
