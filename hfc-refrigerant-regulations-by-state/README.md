# HFC refrigerant GWP regulations by US state

State-level HFC refrigerant regulations across the US, including GWP limits, equipment-type restrictions, effective dates, and regulatory citations. Each record is one state's regulation for one equipment category (supermarket, new facility, stand-alone unit, bulk HFC sales). Answers 'what refrigerant GWP limit applies to new supermarket systems in California', 'which states have adopted SNAP Rules 20 and 21', 'New York HFC phase-down GWP thresholds', and 'can I use R-410A in a new commercial refrigeration system in [state]'.

Canonical, always-current version: https://referencesource.org/hfc-refrigerant-regulations-by-state/
Machine-readable: https://referencesource.org/hfc-refrigerant-regulations-by-state/data.json

Every value carries the source URL it came from and a verbatim quote
from that source. Records are individually addressable at
`https://referencesource.org/hfc-refrigerant-regulations-by-state/<record-id>/`.
