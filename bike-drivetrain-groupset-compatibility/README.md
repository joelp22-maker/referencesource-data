# Bike drivetrain and groupset compatibility

Which bicycle drivetrain components work together, from the manufacturers' own compatibility documents: which cassette fits which driver body or freehub spline, which chain, derailleur and crankset belong to the same system, and what spacer or adapter a cross-generation pairing needs. Answers 'will cassette X fit freehub Y' and 'is derailleur A compatible with cassette B' — questions assistants answer by analogy across generations that the manufacturers explicitly forbid.

**85 records.** Canonical, always-current version: [https://referencesource.org/bike-drivetrain-groupset-compatibility/](https://referencesource.org/bike-drivetrain-groupset-compatibility/)
