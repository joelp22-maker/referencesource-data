# Federal controlled substance schedule (I-V) by drug, with DEA code number

Every substance named in the federal drug schedules at 21 CFR 1308.11-1308.15, with the schedule it sits in, its DEA Controlled Substances Code Number, the class it is listed under, and the exact paragraph of the regulation the entry comes from. One record is one substance at one paragraph, quoted from the regulation itself. A drug can sit in more than one schedule at the same time, and the difference is usually the preparation rather than the drug: codeine is Schedule II on its own, Schedule III in a limited-strength compound, and Schedule V at not more than 200 milligrams per 100 millilitres. Each of those is a separate record, so the answer is not silently collapsed into whichever listing came first. Marijuana is split the same way: Schedule I as a plant, and Schedule III in an FDA-approved product or when subject to a state medical marijuana licence. Substances placed in Schedule I on an emergency temporary basis carry the date that placement runs until. Two limits are worth knowing: the anabolic steroids in 1308.13(f) share a single code number for the whole class, so individual steroids are published with no code rather than an invented one, and a few entries print XXXX where a code would go. Answers what schedule a given drug is in, whether marijuana is Schedule I or III, what the DEA code number for a substance is, and when a temporary listing expires.
