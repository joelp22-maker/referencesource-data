# Plumbing fitting and pipe thread standards

Dimensional specifications for NPT and BSP pipe thread sizes used in plumbing, hydraulic, and gas fittings worldwide. For each nominal pipe size within each standard, gives threads per inch, pitch, major diameter, and minor diameter — the numbers needed to identify an unknown thread or confirm whether two fittings will mate. Combines American (ASME B1.20.1) and British/ISO (ISO 228, ISO 7) standards in one table so the critical differences are visible side by side.
