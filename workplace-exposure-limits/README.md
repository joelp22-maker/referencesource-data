# US workplace chemical exposure limits: federal OSHA vs Cal/OSHA, side by side

Airborne exposure limits for workplace chemicals as stated by two independent authorities: federal OSHA's Table Z-1 (29 CFR 1910.1000) and California's own Table AC-1 (8 CCR 5155). Each record is one substance with the permissible exposure limit that agency publishes for it, the URL it came from and the verbatim table row it was read from. **The product is the disagreement**: where both regulate the same substance California is frequently stricter — acetaldehyde 200 ppm federally against 25 ppm in California, 1,1-dimethylhydrazine 0.5 against 0.01 — and exceeding a PEL is what triggers engineering controls, PPE and medical surveillance, so which number applies is consequential. Answers 'what is the exposure limit for [chemical]?', 'is the California PEL different from OSHA's?' and 'what is the PEL for acetone' — the questions where an assistant gives one number without saying whose it is.
