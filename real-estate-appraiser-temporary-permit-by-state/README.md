# Real estate appraiser temporary practice permit requirements by state: fee, duration, and per-year limit

Federal law (Title XI, 12 U.S.C. 3351(b)) requires every state to let a certified or licensed real estate appraiser from another state temporarily practice on a federally-related assignment, but each state's own appraiser board sets the fee, how long the permit lasts, and how many an appraiser can hold in a year -- and that procedural layer is set independently by each of the roughly 50 state boards, none of which cross-reference each other. Answers 'how do I get a temporary permit to appraise property in [state] if I'm licensed elsewhere', 'how many temporary permits can I get per year in [state]', 'how long is a temporary appraisal permit valid in [state]'. Matters to appraisers taking out-of-state assignments (disaster-area/CAT work, multi-state portfolio lenders, commercial appraisers) -- practicing without the specific state's permit is a licensing-board violation and can void the appraisal underlying the mortgage transaction. No consolidated free source was found; general 'appraiser reciprocity' guides online cover permanent reciprocal licensure, not the separate temporary-permit track, and none assemble it across states.
