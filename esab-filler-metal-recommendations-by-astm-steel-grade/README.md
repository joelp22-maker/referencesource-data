# ESAB recommended filler metals and suggested preheat group, by ASTM steel grade

Which filler metals ESAB recommends for welding a given ASTM steel grade, and which of its four preheat groups (A-D) that grade falls in. Answers 'what ESAB rod do I use to weld ASTM A106 Grade C pipe'. WHICH WELDING PROCESSES THESE PAGES COVER: all six that the source covers, as of 2026-09-16. ESAB's table runs across FACING pages. The left page carries the preheat group, stick (SMAW) and gas-shielded wire/rod (GMAW/GTAW); the right page recommends fillers for the same grade rows under submerged arc (SAW), gas-shielded flux-cored (FCAW), self-shielded flux-cored (FCAW) and metal-cored (MCAW). 699 of the 794 records now answer at least one of those four. The other 95 give the left page only, for two different reasons, and neither is an omission that can be quietly filled in: 57 of them sit in 10 ASTM blocks (A269, A487, A508, A333, A334, A420, A989, A536, A494, A589) where one row of the block is blank on the right and nothing in the PDF says WHICH end it is blank at, so every row in the block could be shifted by one; the remaining 38 are rows where ESAB prints no right-hand recommendation at all. A row we cannot place is left empty rather than guessed, because guessing would invent a welding recommendation for a named steel. HOW THE ROW ALIGNMENT WAS PROVED, since the right page carries no ASTM or grade column and a row's only identity is its position: every block is anchored in a second, column-major reading of the same PDF and its four left-hand columns consumed out of that reading character for character, then each row placed by the span of the surviving blank lines rather than by packing lines from the top. That is checked against the source itself, not assumed -- of the 704 placed rows, 347 name an alloy on BOTH pages (308L, B3, 2209, NiCrMo-3), and in all 347 the two pages agree; shifting the join by one row inside the same block drops that agreement to 36%. The hand check the brief asked for passes: A47 and A48 both read 'OK NiFeCI-A/NiFeCI-A0' on the left and both land on 'NC 55' under gas-shielded flux-cored with the other three processes blank. Every record comes from one section of one manufacturer's databook, headed on the page itself as 'Recommended ESAB Filler Metals' -- so this is that vendor's advice, not a vendor-neutral cross-reference, and the name says so. Two things follow from that. First, the filler values are ESAB product names (Atom Arc 7018, Spoolarc 120, OK 61.81) and ESAB group codes, and a group code is defined separately for each welding process: 'Group 1' for stick means SW 6010 / SW 10P / SW 6011 / SW 6013 / SW 7014, while 'Group 1' for MIG means Spoolarc 29S / 82 / 86 / 87HP / Aristorod 12.50. Same label, different products; the databook expands both in its own legend at printed page 7-2, and each record now carries the expansion for the group its own row names, quoted from under that legend's process heading. Second, the preheat value is a letter and not a temperature: A-D index a preheat-temperature-by-steel-thickness table at the head of the section. That table is now carried too, so a record states the temperatures its letter points to rather than only the letter -- but they remain what the source calls 'suggested ranges', adding 'Check your welding procedure for a more specific preheat temperature.' A vendor-neutral version of this cross-reference does exist but is sold rather than published: AWS's Filler Metal Comparison Charts (FMC:2000). Adding a second manufacturer's catalog would put a second brand's product codes beside these, not turn either into generic ones.
