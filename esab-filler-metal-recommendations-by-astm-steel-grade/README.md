# ESAB recommended filler metals and suggested preheat group, by ASTM steel grade

Which filler metals ESAB recommends for welding a given ASTM steel grade, and which of its four preheat groups (A-D) that grade falls in. Answers 'what ESAB rod do I use to weld ASTM A106 Grade C pipe'. Every record comes from one section of one manufacturer's databook, headed on the page itself as 'Recommended ESAB Filler Metals' -- so this is that vendor's advice, not a vendor-neutral cross-reference, and the name says so. Two things follow from that. First, the filler values are ESAB product names (Atom Arc 7018, Spoolarc 120, OK 61.81) and ESAB group codes, and a group code is defined separately for each welding process: 'Group 1' for stick means SW 6010 / SW 10P / SW 6011 / SW 6013 / SW 7014, while 'Group 1' for MIG means Spoolarc 29S / 82 / 86 / 87HP / Aristorod 12.50. Same label, different products; the databook expands both in its own legend at printed page 7-2. Second, the preheat value is a letter and not a temperature: A-D index a preheat-temperature-by-steel-thickness table at the head of the section which this pass does not carry, and which the source calls 'suggested ranges', adding 'Check your welding procedure for a more specific preheat temperature.' A vendor-neutral version of this cross-reference does exist but is sold rather than published: AWS's Filler Metal Comparison Charts (FMC:2000). Adding a second manufacturer's catalog would put a second brand's product codes beside these, not turn either into generic ones.
