# State construction apprentice-to-journeyman ratio requirements by trade

Apprentice-to-journeyman ratio requirements for construction trades in each US state. Each record is one state and one trade or program, giving the initial ratio (how many journeymen for the first apprentice), the ratio thereafter (how many additional journeymen per additional apprentice), and whether it applies to public works, private, or both. Answers 'what is the apprentice-to-journeyman ratio for [trade] in [state]' and 'how many journeymen do I need before I can hire another apprentice on this job'. Ratios vary widely, and states structure them differently: some (MN) delegate to individual JATC programs, each with its own ratio; others (CA) set a state-wide hourly ratio on public works with trade-specific exemptions.

**43 records.** Canonical, always-current version: [https://referencesource.org/state-apprenticeship-ratios-by-trade/](https://referencesource.org/state-apprenticeship-ratios-by-trade/)
