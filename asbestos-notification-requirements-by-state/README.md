# Asbestos Abatement Notification Requirements, Thresholds, and Fees by State

Notification requirements for asbestos abatement and demolition projects vary by state. The federal NESHAP (40 CFR 61 Subpart M) requires 10 working days' notice for projects exceeding 260 linear feet, 160 square feet, or 35 cubic feet of regulated asbestos-containing material. States with delegated authority impose their own notification fees, advance-notice periods, material quantity thresholds, and exemptions. This table gives the notification trigger, advance-notice period, fee structure, and delegated authority for each state so a contractor knows what is required before starting work.
