# Hazmat load segregation — which hazard classes may travel together, highway vs vessel

The pairwise load-segregation rules for hazardous materials: for each pair of hazard classes/divisions, whether they may be loaded, transported or stored together on a highway vehicle (49 CFR 177.848) or on a vessel (49 CFR 176.83). One record is one intersection under one mode: the two classes, the code the table prints in that cell ('X' may not be loaded together, 'O' separated so no commingling on leakage, '*' see the class-1 compatibility table, blank no restriction, plus the ammonium-nitrate note 'A'), and what that code requires in the section's own words. Resolving the code is what the page is for — the table prints a bare letter and its meaning sits in a note paragraph further down the section, so reading one cell off the regulation takes two lookups. Both modes are in the dataset, as separate records: the two tables label their Class 1 rows differently ('1.1 and 1.2' on highway against '1.1, 1.2, 1.5' on vessel), so putting one pair's two answers on a single page is a mapping decision and not a fold. Answers 'can Division 4.3 ride with Class 8 corrosive liquids' (yes on highway with separation — the O cell), 'can I load oxidizers with flammable liquids', and the per-pair questions shippers and freight brokers ask before booking mixed loads. A pairwise matrix is a shape the portfolio has not tried: the record is an intersection, not a row.
