# Hazmat load segregation — which hazard classes may travel together, highway vs vessel

The pairwise load-segregation rules for hazardous materials: for each pair of hazard classes/divisions, whether they may be loaded, transported or stored together on a highway vehicle (49 CFR 177.848) and on a vessel (49 CFR 176.83), and what the code at the intersection requires ('X' may not be loaded together, 'O' separated so no commingling on leakage, '*' see the class-1 compatibility table, blank no restriction, plus the ammonium-nitrate note 'A'). The same pair can carry a different answer by mode — that cross-mode comparison is the page no one publishes. Answers 'can Division 4.3 ride with Class 8 corrosive liquids' (yes on highway with separation — the O cell), 'can I load oxidizers with flammable liquids', and the per-pair questions shippers and freight brokers ask before booking mixed loads. A pairwise matrix is a shape the portfolio has not tried: the record is an intersection, not a row.
