# US state unclaimed property dormancy periods by property type

How many years of inactivity before each type of property (wages, checks, insurance proceeds, utility deposits, gift cards, safe-deposit boxes, securities, etc.) must be reported as unclaimed in each US state. Each record is one state + property type with the dormancy period in years, the statute citation, and any conditions (e.g. dual thresholds for solids, different rules for government-held funds). Answers 'how long before uncashed payroll in [state] is escheatable?', 'what is the dormancy period for life insurance in [state]?', and 'which states have the shortest dormancy for [property type]?' — questions where the answer varies by state AND property type, and where getting it wrong triggers penalties and audit exposure.

**81 records.** Canonical, always-current version: [https://referencesource.org/state-unclaimed-property-dormancy-periods/](https://referencesource.org/state-unclaimed-property-dormancy-periods/)
