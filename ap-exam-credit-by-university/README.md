# AP exam score to college credit, compared across universities

What each university actually grants for a given AP exam score: which course the credit maps to, how many units or credit hours, and the minimum score required. One record is one AP exam at one institution, so a single exam page compares institutions side by side. Answers 'which universities give credit for a 3 on AP Chemistry', 'AP Calculus BC score 4 college credit', 'does a 3 on AP Chemistry count for anything', 'AP credit policy Georgia Tech', and 'UCLA AP Calculus BC credit'. There is no rule to infer: a 3 on AP Calculus BC earns 8 units of Calculus at UCLA, subject credit for Mathematics 1A at Berkeley, and nothing at Georgia Tech, which requires a 4 or 5. College Board runs an AP Credit Policy Search but it is a JavaScript application that serves no policy content to a fetcher, so the assembled comparison is effectively unreadable.

Every record carries `source` (the page it came from) and `source_quote` (the exact line on that page which states it), so any value here can be checked without asking us. Where a source does not state something the row is omitted rather than guessed.

**Licence position for this dataset.** Facts extracted from freely published university catalog and registrar pages, with a short attributed quote and a link back to each institution's own page. Credit-award tables are institutional policy statements, not creative compilations; what is taken is one factual row per exam plus an attributed quote. No source page carries a restrictive notice.
