# Postal shipping restrictions by item category

What item categories each postal carrier prohibits, restricts, or allows, with the conditions that apply. Covers USPS (domestic US) and Royal Mail / Post Office (UK domestic and international). Answers 'can I send a lighter by Royal Mail internationally', 'USPS lithium battery shipping rules' and 'is [item] prohibited or restricted by [carrier]'.

Canonical, always-current version: https://referencesource.org/shipping-restrictions-by-class/
Machine-readable: https://referencesource.org/shipping-restrictions-by-class/data.json

Every value carries the source URL it came from and a verbatim quote
from that source. Records are individually addressable at
`https://referencesource.org/shipping-restrictions-by-class/<record-id>/`.
