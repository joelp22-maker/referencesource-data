**Item category:** Sharps and regulated medical waste containing Category B infectious substance (UN3291)

**Carrier:** USPS

**Restriction type:** restricted

**Scope:** domestic mail via USPS Ground Advantage only

**Conditions:** Permitted via USPS Returns Service via USPS Ground Advantage only; vendor must obtain prior authorization; strict packaging, testing, labeling requirements apply

> Regulated medical waste and sharps medical waste as defined in 346.12 ( f ) and 346.12 ( g ) and containing materials classified as Category B infectious substances must be marked UN3291 and are permitted for mailing only using USPS Returns Service (refer to DMM 505.3) via USPS Ground Advantage service.
