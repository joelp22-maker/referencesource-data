# Building permit expiry, progress and renewal rules by jurisdiction

How long a building permit stays valid, what keeps it alive, what it costs to renew once it has lapsed, and how the local rule differs from the model-code section it amends. One record is one rule for one jurisdiction, placed next to the adopted code section it replaces. Answers 'how long is a building permit valid before it expires', 'does an inspection reset the permit clock', 'my building permit expired what do I do', 'building permit renewal fee after expiration', and 'IRC 105.5 permit expiration'. The memorised answer is 180 days and it is wrong in the places people ask about: unincorporated San Diego County allows two years to start work, then requires a passed inspection every 180 days, with an outer life of three years and renewal at one-half of current permit fees — one-quarter if only a final inspection remains. DC's adopted code gives one year to begin, with a 180-day carve-out for residential work and no more than four extensions per permit.

Every record carries `source` (the page it came from) and `source_quote` (the exact line on that page which states it), so any value here can be checked without asking us. Where a source does not state something the row is omitted rather than guessed.

**Licence position for this dataset.** Facts extracted from freely published municipal and county building department pages and from published jurisdiction-amended code sections, with a short attributed quote and a link back. Expiry periods and renewal fee bases are facts about a legal requirement, not reproductions of a standards developer's expression. UpCodes is used only for the amended-section value with a short attributed quote, never as a bulk source: its product IS the compilation of code text and it is in active litigation with ICC and ASTM over exactly that. Prefer the jurisdiction's own publication wherever it exists.
