# EPA NESHAP Source Category Applicability Crosswalk

Maps each EPA NESHAP source category to its 40 CFR subpart, whether it applies to major or area sources, the original final rule date, most recent amendment, and residual risk/technology review status.

**125 records.** Canonical, always-current version: [https://referencesource.org/neshap-source-category-crosswalk/](https://referencesource.org/neshap-source-category-crosswalk/)
