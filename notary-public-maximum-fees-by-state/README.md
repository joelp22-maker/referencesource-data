Every record carries `source` (the page it came from) and `source_quote` (the exact line on that page which states it), so any value here can be checked without asking us. Where a source does not state something the row is omitted rather than guessed.

**Licence position for this dataset.** Facts from state statutes; statutory text is government work and the facts in it are not copyrightable (Feist, 1991). Each record quotes a short attributed excerpt and links back to the page it was read from. Citation note, checked 2026-10-14: The Georgia rows are cited to codes.findlaw.com rather than to an official state host, because Georgia does not publish its code anywhere a single section can be fetched at a stable URL — Georgia's own free O.C.G.A., which the General Assembly contracts LexisNexis to publish, is a JavaScript application at advance.lexis.com that serves no statutory text to a fetch. That mirror now sits behind a Cloudflare challenge and returns 403 to everyone, an invented-slug control included, so these rows cannot at present be re-checked against the page they cite. The values were read from those pages when the records were harvested and nothing here has changed them; what is missing is any ongoing check that they are still current.
