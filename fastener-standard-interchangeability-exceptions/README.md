# DIN / ISO / BS fastener equivalents and the sizes where they are not interchangeable

Equivalence between withdrawn DIN fastener standards and their current ISO and BS counterparts, and -- the part that is missing everywhere else -- the specific sizes at which the supposedly equivalent parts have different dimensions. Each record is one DIN standard with its ISO and BS counterpart and the publisher's interchangeability verdict, or one size at which a named dimension differs between the two standards. Answers 'is DIN 933 the same as ISO 4017', 'DIN 912 vs ISO 4762 are they interchangeable', 'my drawing says DIN 931 and my distributor only stocks ISO 4014', 'what replaced DIN 934', and 'DIN 125 ISO equivalent washer'. The headline mapping is easy and everyone publishes it; the exception detail is where free sources fail and contradict each other. Wurth, the German distributor that wrote the original catalogues, prints four sizes at which the width across flats changed between DIN 933 and ISO 4017 -- M10 17 mm becomes 16 mm, M12 19 becomes 18, M14 22 becomes 21, M22 32 becomes 34 -- meaning a different spanner. Monster Bolts lists the same pair as fully interchangeable. Both verdicts are published here, attributed, side by side, because the disagreement is the fact.

Every record carries `source` (the page it came from) and `source_quote` (the exact line on that page which states it), so any value here can be checked without asking us. Where a source does not state something the row is omitted rather than guessed.

**Licence position for this dataset.** Facts extracted from freely published distributor technical pages. Dimensions are facts, not copyrightable expression (US: Feist, 1991). ISO 4017 and the other ISO fastener documents were not purchased or opened; ISO's own terms restrict use of ISO content, and no ISO content is used here -- only dimensions as facts, quoted from distributors who published them. Three separate distributors, no bulk take from any one: the exception rows come from Wurth, the pair list from Monster Bolts, the BS column from TR Fastenings.
