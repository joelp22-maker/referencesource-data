# File format magic numbers

The leading bytes (magic number / file signature) that identify a file format, with its usual extension. Answers 'what actually is this file' when the extension is wrong or missing.

Canonical, always-current version: https://referencesource.org/file-format-signatures/
Machine-readable: https://referencesource.org/file-format-signatures/data.json

Every value carries the source URL it came from and a verbatim quote
from that source. Records are individually addressable at
`https://referencesource.org/file-format-signatures/<record-id>/`.
