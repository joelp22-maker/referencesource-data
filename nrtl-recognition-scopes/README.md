# Which OSHA NRTL is recognized for which test standard: all 21 labs' scopes of recognition, cross-referenced

For every OSHA Nationally Recognized Testing Laboratory (NRTL), each test standard the lab is currently recognized for, taken from the lab's own scope-of-recognition page on osha.gov. One record per lab-standard pair. OSHA publishes each lab's scope on a separate page and publishes no cross-lab view, so answering 'which NRTLs can certify to UL 507?' or 'is DEKRA recognized for ANSI/AAMI ES 60601-1?' or 'which labs besides UL can certify commercial cooking appliances?' today means opening up to 21 pages and searching each one. The recognition matters commercially: a product that 29 CFR 1910.7 requires to be NRTL-certified must be certified by a lab whose scope covers the applicable standard, and manufacturers choosing a lab, buyers verifying a certification mark, and safety engineers checking whether a mark is valid for a given standard all need the standard-to-lab direction that OSHA does not publish.

**3,321 records.** Canonical, always-current version: [https://referencesource.org/nrtl-recognition-scopes/](https://referencesource.org/nrtl-recognition-scopes/)
