# Domain registrar accreditation status and ICANN enforcement history, by IANA ID

Whether a domain name registrar is still ICANN-accredited, and what enforcement action ICANN has taken against it. Each record is one registrar identified by its IANA registrar ID, carrying the accreditation status IANA publishes ('Accredited', 'Terminated', 'Reserved') and, where one exists, the dated ICANN Contractual Compliance notice ('Notice of Breach', 'Notice of Suspension', 'Notice of Termination', 'Notice of Non-Renewal') with the date and the notice PDF. Answers 'is my domain registrar still ICANN accredited', 'which registrars lost their accreditation in 2026', 'is IANA ID 3221 accredited', 'what happens to my domain if my registrar is terminated', and 'has this registrar been issued a breach notice'. The two authorities publish complementary halves and neither publishes the other's: IANA states a registrar is Terminated but never says when or why, and ICANN dates every enforcement action but never states current status. A registrar termination triggers a bulk transfer of every domain under it, so the answer is consequential and it changes several times a year.
