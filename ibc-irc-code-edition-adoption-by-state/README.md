# Which edition of the International Building Code, Residential Code and 15 other I-Codes the ICC's adoption chart of January 2024 records for each US state

What the International Code Council's own I-Code adoption chart, published January 2024, records for each US state and territory. The ICC publishes 17 code families (IBC, IRC, IFC, IMC, IPC, IPSDC, IFGC, IgCC, IPMC, IEBC, ISPSC, ICCPC, IWUIC, IZC, ICC 700) and states adopt different editions of each, so the chart is a grid of state against code family and each record here is one state's row of it -- the chart records Ohio at IBC 2015 but IRC 2018, Texas at IBC 2012 and IRC 2012, Wyoming at IBC 2021 with the IRC adopted only locally. This is a January 2024 snapshot and not a statement of what is in force today. Fifteen states have now been checked against their own adopting regulation. Five match the chart and ten do not, and the misses do not all run the same way: Washington and Pennsylvania read 18 where the regulation adopts the 2021 edition, New Mexico and Wisconsin read 15 where it adopts 2021, Rhode Island reads 18 where it adopts 2021, New Jersey reads 21 where the subcodes are already on the 2024 editions, Iowa reads 15 where the rule adopts the 2024 editions -- three editions of drift, the widest found so far -- and New Hampshire reads 18 where the law is already on the 2024 editions. But Virginia's 21, Minnesota's 18, Nebraska's 18, Kentucky's 15 and South Carolina's 21 are all exactly right, so an old-looking year in a cell is not by itself a sign the cell is stale, and a recent-looking one is not a guarantee. For the edition actually in force, read the state's own adopting regulation -- which is what the two 'in force' columns below do, where they are present. Since 2026-09-30 some states carry two further columns that do exactly that -- 'IBC edition in force' and 'IRC edition in force', each quoted from the state's own adopting regulation and not from this chart, with the regulation named beside them -- so those pages show the chart's January 2024 value and the law side by side. Fifteen states are done. Virginia, Minnesota, Nebraska, Kentucky and South Carolina agree with the chart; Washington, Pennsylvania, New Mexico, Rhode Island and Iowa are behind it, Iowa by three editions, its cell reading 15 against a rule on the 2024 codes; New Jersey is one edition behind on both families; New Hampshire is two editions behind in the other direction, because the state moved on to the 2024 codes and the chart still reads 18; Wisconsin is two editions behind on the IBC and adopts no IRC edition at all, substituting its own Uniform Dwelling Code; Michigan is two editions behind on the IBC while its IRC column, which reads 15, is still right, because Michigan updated its building rules and left its residential rules alone; and Oregon is the same shape, its structural code now built on the 2024 IBC while its residential code stays on the 2021 IRC, which is what the chart's 21 already says. Those are the useful warning -- whether the chart is stale turns on the code family, not on the chart's own value, so a state's columns can be right and wrong at the same time. What does not go stale at that rate is coverage -- whether a state has adopted a given code family at all, and whether statewide or only locally -- and that is what this chart is good for. Every record carries the chart's own date as 'Chart as of'. Editions are printed as two-digit years, per the chart's own key: 21 = 2021, 18 = 2018, 15 = 2015, 12 = 2012, 09 = 2009, 06 = 2006, 04 = 2004, 03 = 2003, 00 = 2000. 'X' means one or more state or local agencies have adopted an edition of that code, but it is not used as a standard for all buildings, and a code family is left blank here when the chart shows no adoption in that state. Three cells are printed with an asterisk (Hawaii IPC 'X*', Idaho ISPSC '*15', Oregon IWUIC 'X*'); the chart carries no legend for it in any of the three ways the PDF can be read, so the asterisk is reproduced as printed and not interpreted. New Jersey's fire code cell reads '15 (IBC)' -- the chart's legend glosses parentheses as a stretch code, but here the parenthetical names the code the provisions come from, so it too is reproduced as printed. American Samoa's building code cell reads '1964 UBC', an edition of the Uniform Building Code rather than an I-Code. The two energy columns (IECC-R, IECC-C) are deliberately not published here: energy-code-adoption-by-state carries those from each state's adopting regulation, which is current, whereas this chart's energy values have gone stale since January 2024. NEC/NFPA 70 is covered by nec-edition-adoption-by-state. The other 15 code families (IBC, IRC, IFC, IMC, IPC, IPSDC, IFGC, IgCC, IPMC, IEBC, ISPSC, ICCPC, IWUIC, IZC, ICC 700) are not covered anywhere else in the portfolio.

Every record carries `source` (the page it came from) and `source_quote` (the exact line on that page which states it), so any value here can be checked without asking us. Where a source does not state something the row is omitted rather than guessed.

**Licence position for this dataset.** Source is a freely published PDF chart by the International Code Council. We take facts (which edition each state has adopted) plus short attributed quotes. Facts about code adoption are not copyrightable (Feist, 1991). We do not reproduce the codes themselves.
