# Which edition of the International Building Code, Residential Code and 15 other I-Codes each US state enforces, from the ICC's own published adoption chart

Which edition of each International Code Council (ICC) code family is adopted in each US state and territory, taken from the ICC's own published adoption chart. The ICC publishes 17 code families (IBC, IRC, IFC, IMC, IPC, IPSDC, IFGC, IgCC, IPMC, IEBC, ISPSC, ICCPC, IWUIC, IZC, ICC 700), and states adopt different editions of each -- Ohio is on IBC 2015 but IRC 2018, Texas is on IBC 2012 but IRC 2012, Wyoming is on IBC 2021 but has adopted the IRC only locally. Each record is one state, with the adopted edition year for each code family. Answers 'what edition of the IBC is adopted in Ohio', 'which states are still on IBC 2012', 'does my state enforce the International Plumbing Code', 'what building code edition applies in Texas'. This is the ICC's own snapshot, dated on the chart and carried on every record as 'Chart as of'; a state that has adopted a newer edition since that date will still show the edition the chart recorded. Editions are printed as two-digit years, per the chart's own key: 21 = 2021, 18 = 2018, 15 = 2015, 12 = 2012, 09 = 2009, 06 = 2006, 04 = 2004, 03 = 2003, 00 = 2000. 'X' means one or more state or local agencies have adopted an edition of that code, but it is not used as a standard for all buildings, and a code family is left blank here when the chart shows no adoption in that state. Three cells are printed with an asterisk (Hawaii IPC 'X*', Idaho ISPSC '*15', Oregon IWUIC 'X*'); the chart carries no legend for it in any of the three ways the PDF can be read, so the asterisk is reproduced as printed and not interpreted. New Jersey's fire code cell reads '15 (IBC)' -- the chart's legend glosses parentheses as a stretch code, but here the parenthetical names the code the provisions come from, so it too is reproduced as printed. American Samoa's building code cell reads '1964 UBC', an edition of the Uniform Building Code rather than an I-Code. The two energy columns (IECC-R, IECC-C) are deliberately not published here: energy-code-adoption-by-state carries those from each state's adopting regulation, which is current, whereas this chart's energy values have gone stale since January 2024. NEC/NFPA 70 is covered by nec-edition-adoption-by-state. The other 15 code families (IBC, IRC, IFC, IMC, IPC, IPSDC, IFGC, IgCC, IPMC, IEBC, ISPSC, ICCPC, IWUIC, IZC, ICC 700) are not covered anywhere else in the portfolio.

Every record carries `source` (the page it came from) and `source_quote` (the exact line on that page which states it), so any value here can be checked without asking us. Where a source does not state something the row is omitted rather than guessed.

**Licence position for this dataset.** Source is a freely published PDF chart by the International Code Council. We take facts (which edition each state has adopted) plus short attributed quotes. Facts about code adoption are not copyrightable (Feist, 1991). We do not reproduce the codes themselves.
