# Firewall and network security appliance hardware end-of-life dates by brand

End-of-sale and end-of-support dates for the physical hardware of firewall and network security appliances (not the OS or firmware version, the box itself), taken from each manufacturer's own hardware lifecycle page. Answers 'when does support end for [model] firewall hardware', the question a network admin planning a refresh needs answered, where the free software-lifecycle aggregators (e.g. endoflife.date) do not cover hardware end-of-support and each vendor's own lifecycle page uses a different format and a different name for the same two dates.

**93 records.** Canonical, always-current version: [https://referencesource.org/firewall-hardware-end-of-life-dates-by-brand/](https://referencesource.org/firewall-hardware-end-of-life-dates-by-brand/)
