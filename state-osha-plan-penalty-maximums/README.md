# State OSHA plan civil penalty maximums by violation type compared with federal

Maximum civil penalty amounts for workplace safety violations in each OSHA-approved State Plan, compared with the federal OSHA baseline. Each record is one state-plan jurisdiction and one violation type (serious, willful, repeat, other-than-serious, failure-to-abate, regulatory/posting). Gives the state's maximum and minimum penalty, the corresponding federal amount, and key structural differences in how the penalty is computed (severity tiers, employer-size reductions, good-faith adjustments). Answers 'what is the maximum fine for a serious OSHA violation in [state]' and 'how does [state]'s penalty structure differ from federal OSHA'. Special note for 2026: the October 2025 CPI-U was not produced due to the government shutdown, so federal penalties were not adjusted — but some state plans (CA, OR) adjusted independently, widening the gap.
