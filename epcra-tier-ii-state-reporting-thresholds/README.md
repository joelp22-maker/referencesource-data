# EPCRA Tier II hazardous chemical inventory reporting thresholds by state

The quantity threshold at which a facility must file an annual Tier II hazardous chemical inventory report in each US state, compared to the federal EPCRA Section 312 baseline. Federal thresholds: ≥10,000 lbs for hazardous chemicals, ≥500 lbs or the threshold planning quantity (whichever is lower) for extremely hazardous substances (40 CFR Part 370). EPA authorizes states to set lower thresholds and add chemicals, and at least 9 states have done so: California (55 gal/500 lbs), Louisiana (500 lbs), Vermont (100 lbs — among the strictest), Delaware (55 gal/500 lbs), Oregon (dual-level system), Nevada (IFC-based, some categories at 0 lbs), Alaska (any quantity for certain hazard classes), New Jersey (own EHS list), and New York City (own EHS list with very low thresholds). Answers 'does my California facility need to file Tier II for 600 pounds of a hazardous chemical' (yes — California threshold is 500 lbs, below the federal 10,000), 'what is Nevada's reporting threshold for flammable materials', and 'which states have lower Tier II thresholds than federal'.
