# Respirator assigned protection factors — federal OSHA and Cal/OSHA, with maximum use concentrations

Assigned protection factors (APFs) for each respirator class under federal OSHA (29 CFR 1910.134 Table 1) and Cal/OSHA (8 CCR 5144), and — the derived layer — the maximum use concentration (MUC) each respirator class supports for a given substance, computed as APF × the applicable exposure limit. The regulation itself states the formula ('The MUC can be determined mathematically by multiplying the assigned protection factor... by the required OSHA permissible exposure limit'), but nobody publishes the computed per-substance table, and OSHA and Cal/OSHA limits differ up to 10× for 66 substances — so the same respirator is adequate federally and inadequate in California for the same job. Answers 'what APF does a half mask have', 'what respirator do I need for styrene at 300 ppm', and 'is my respirator sufficient under Cal/OSHA'. Pairs with the existing workplace-exposure-limits asset (1,184 records, two authorities) — the MUC pages are that asset multiplied through this one.
