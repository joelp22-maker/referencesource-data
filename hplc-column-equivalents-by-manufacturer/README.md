# HPLC column equivalents to other manufacturers' columns

Which replacement HPLC column is offered for a named column from another manufacturer, keyed on the column being replaced. A lab whose method is built around a discontinued or hard-to-source column needs a same-selectivity substitute, and the vendors publish their own mappings from a competitor's column name to their own product. Built from two manufacturers' published cross-reference charts: GL Sciences' equivalent list (Agilent, Waters, Phenomenex, Thermo Fisher, Sigma-Aldrich/Merck, YMC, Restek, Shimadzu) and Waters' Column Comparison Chart (seventeen manufacturers, including GL Sciences itself). Every vendor's chart is one-directional, listing only its own equivalents to competitors, and no single original publishes this across manufacturers -- the synthesis value is in merging them onto the column being replaced, so that a record can carry both vendors' answers side by side and the two run in opposite directions. Records where both vendors answer are the ones worth having; the rest still answer a question with no other published source.
