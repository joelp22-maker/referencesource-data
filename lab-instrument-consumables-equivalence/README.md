# GC column stationary phase cross-reference by manufacturer

A cross-reference of gas chromatography (GC) capillary column stationary phases across manufacturers, showing which column product names from Agilent, Restek, Phenomenex, Supelco/Merck, GL Sciences, GS-Tek, Trajan/SGE, Macherey-Nagel, Quadrex, PerkinElmer, and others correspond to the same underlying phase chemistry. Each record is one stationary phase family (e.g. '100% dimethylpolysiloxane' or 'polyethylene glycol'), identified by its chemical composition and USP G-code(s), with the equivalent column product names from each manufacturer listed. Built from the published cross-reference tables of three column manufacturers (GL Sciences, GS-Tek, Restek), each of which maps its own products to competitors'. No single original publishes this for all manufacturers — every vendor's table is one-directional, listing only its own equivalents to competitors. The synthesis value is in merging them into a single multi-directional lookup. Answers 'what GC column from Restek is equivalent to an Agilent DB-5ms', 'what USP G-code does this phase carry', 'which manufacturers make a 14% cyanopropylphenyl column', and 'what is the phase chemistry of a ZB-WAX column'.
