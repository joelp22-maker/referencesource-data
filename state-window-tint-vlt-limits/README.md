# State Window Tint Darkness (VLT%) Limits by Window Position

Every state sets its own minimum visible-light-transmittance (VLT) percentage for aftermarket window tint, and the limit is usually different for the windshield, front side windows, rear side windows, and rear window -- so the same tint film can be legal in one state and a ticket in the next, and legal on the back windows but not the front. States revise these numbers periodically (Iowa's front-side-window minimum dropped from 70% to 50% effective 1 July 2026 under House File 766, while Iowa's own implementing administrative rule, 761 IAC 450.7, still states the old 70% figure), and the free tint-shop guides that circulate are inconsistent about it: one popular guide's Iowa page, dated before the law was even signed, still shows 70%. A car owner or installer asking 'how dark can I legally tint my windows here' needs the current, per-window, per-state percentage from the statute itself.
