# How often elevators must be inspected in each US state: intervals, filing rules, fees and the ASME A17.1 edition enforced

Per-state elevator inspection requirements: how often a passenger elevator must be inspected, who performs and files the inspection, the filing fee and deadline, the penalty for a missed inspection, and which edition of the ASME A17.1 safety code the state enforces. The variation is large: Texas requires inspection every 12 months with the report and $20-per-unit fee filed to TDLR within 30 days, and administrative penalties up to $5,000 per day for missed inspections (Texas Health & Safety Code ch. 754); New York City tests twice annually with a Category 5 load test every five years; the enforced A17.1 edition spans roughly 2004 (California) to 2019 (Connecticut). Answers 'how often does my building's elevator need to be inspected?', 'what happens if the elevator inspection is late?', 'which ASME A17.1 edition does my state enforce?'
