# Power tool battery and accessory compatibility

Which power tool batteries, chargers, adapters and accessory interfaces work with which tools and platforms, from the manufacturers' and battery alliances' own pages: which brands belong to the AMPShare and CAS cross-brand 18V battery systems, which DEWALT tools the DCA1820 18V adapter fits, what FLEXVOLT batteries run in, what a Starlock or SDS shank fits, and what restrictions the manufacturer attaches. Answers 'will battery X run tool Y' and 'which brands share this battery' from the body that publishes the fact.
