# Small Claims Court Dollar Limits by State

Every state sets its own maximum dollar amount a plaintiff may sue for in small claims court, and the limit for an individual often differs from the limit for a business entity. Filing above the limit forces a case into a higher (and much more expensive) court. This table gives, for each state, the small claims dollar limit for individuals, the limit for business/corporate plaintiffs where it differs, and the court name that hears the case, so someone deciding where to file knows the ceiling before they start.
