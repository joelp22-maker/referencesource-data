# TP-Link and ASUS routers and network gear — end-of-life and end-of-support dates by model

End-of-life and end-of-support dates for TP-Link and ASUS home networking gear, each read off the vendor's own end-of-life list and quoted from it. TP-Link records carry the date support ended; ASUS records say only that the model is on ASUS's end-of-life list, because that list prints no dates. In full: TP-Link's Home EOL list prints an announcement date and an end-of-support date for each model version and region, and a TP-Link record carries both. ASUS's networking EOL page prints which models are end-of-life and nothing else, so the date columns of an ASUS record are blank because that page states none, not because a date was lost. ASUS does publish end dates for security update support on separate regional pages — https://www.asus.com/event/network/security_update_support/ and a Singapore Cybersecurity Labelling Scheme FAQ — which are a different list from the end-of-life one, cover current models rather than discontinued ones, and are not read here, so no date from them is in these records. Not only routers: about three fifths of the records are routers or mesh systems, and the rest are range extenders, USB and PCIe Wi-Fi adapters, powerline kits, access points and a few cable modems, all of them on the same vendor lists. Not covered: NETGEAR, whose end-of-service lookup returns nothing to an automated reader, so there is no NETGEAR model here; and Linksys, apart from three rows that are software features rather than models. A model that is missing was not on the list we read, which is not the same as the vendor saying it is still supported. Answers 'is my TP-Link Archer C2600 still getting security updates'.
