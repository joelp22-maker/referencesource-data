# Consumer router firmware support — end-of-life status and dates by vendor and model

Per-model end-of-life / end-of-service status for consumer networking gear (routers, mesh systems, extenders), assembled across vendors from each vendor's own EOL publication: Linksys (per-model EOL and end-of-support dates in an HTML table), ASUS (a maintained EOL model list — membership, mostly without dates), TP-Link (dated EOL lists published as PDFs), with each vendor's stated support policy alongside (Netgear: EOS three years after last sale date). Answers 'is my router still receiving security updates' — a question with a real cost to being wrong, which no one has assembled: endoflife.date's device category is 20 consumer phones and tablets with zero router vendors (verified in the 2026-08-10 eol-recon), the enterprise-gear niche is occupied by refurb resellers, and consumer Wi-Fi routers sit in neither. Production-edge case: four vendors, hundreds of models, per-region variation and quarterly list revisions made this prohibitive to maintain by hand; the harvest pipeline makes it an afternoon plus a re-fetch cadence.
