# TP-Link and ASUS routers and network gear — end-of-life and end-of-support dates by model

End-of-life and end-of-support dates for home networking hardware, each read off the vendor's own EOL list and quoted from it. Counted 2026-09-16 across the 987 published records: TP-Link 649 (from TP-Link's dated Home EOL list, which prints an announcement date and an end-of-support date per model and regional SKU) and ASUS 335 (from ASUS's networking EOL page, which prints membership of the end-of-life list and no dates at all), plus three Linksys rows that are software features rather than models — see _curator_2026_09_16. TWO THINGS THIS DOES NOT COVER, both of which the description claimed until 2026-09-16. NETGEAR: no records. Its consumer end-of-service list is a JavaScript model lookup that still returns 'No end of service results found' to a fetcher (re-tested 2026-09-16), and the enterprise EOL PDF its own notes point at downloads to an empty file, so there is nothing here for a NETGEAR owner and the page should not imply there is. Routers only: no. About 600 of the 987 (61%) are routers or mesh systems; the rest are range extenders, USB and PCIe Wi-Fi adapters, powerline kits, a handful of cable modems, access points, a USB hub and a print server — all of them on the vendors' own home-network EOL lists, so they belong here, but a title promising routers alone was describing three fifths of the asset. Answers 'is my TP-Link Archer C2600 still getting security updates', which nobody else has assembled: endoflife.date's device category is 20 consumer phones and tablets with zero router vendors (verified in the 2026-08-10 eol-recon), and the enterprise-gear niche is occupied by refurb resellers.
