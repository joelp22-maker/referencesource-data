# US state universal occupational license recognition laws — conditions and scope

Which US states have passed universal occupational license recognition laws, what conditions they impose (minimum years licensed, good standing, criminal background, exam requirements), which professions are excluded, and whether military spouse provisions are included. Each record is one state's law with its specific conditions. Answers 'does [state] recognize my out-of-state professional license?', 'how long do I need to have been licensed to qualify?', 'are there professions excluded from universal recognition in [state]?', and 'does [state] have a military spouse licensing provision?' — questions where the answer is rapidly changing as states adopt new laws (22+ states as of mid-2026), and where the conditions differ meaningfully between states.

Citation note, checked 2026-10-14: The Georgia row is cited to codes.findlaw.com rather than to an official state host, because Georgia does not publish its code anywhere a single section can be fetched at a stable URL — Georgia's own free O.C.G.A., which the General Assembly contracts LexisNexis to publish, is a JavaScript application at advance.lexis.com that serves no statutory text to a fetch. That mirror now sits behind a Cloudflare challenge and returns 403 to everyone, an invented-slug control included, so these rows cannot at present be re-checked against the page they cite.
