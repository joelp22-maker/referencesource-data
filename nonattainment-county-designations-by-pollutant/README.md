# Current EPA nonattainment county designations by pollutant

Whether a US county is in 'nonattainment' for a given Clean Air Act pollutant (and if so, at what severity classification) drives real obligations for anyone building, permitting, or selling into that county: stricter new-source review, vehicle inspection and reformulated-fuel requirements, and federal highway-funding conditions all key off this status. EPA's Green Book is the single authoritative list, but it is a very long plain-text table with no per-county lookup and no API — a resident, contractor, or small manufacturer has to scan hundreds of rows by hand to find their county. Each record is one county x one pollutant NAAQS combination: whether it is designated nonattainment, the classification if the pollutant test has one (Marginal through Extreme for ozone; Moderate/Serious for PM), and the named nonattainment area it belongs to. Answers 'is [county] in nonattainment for ozone', 'what classification is [county] for PM-2.5', 'does building in [county] trigger nonattainment-area permitting'.
