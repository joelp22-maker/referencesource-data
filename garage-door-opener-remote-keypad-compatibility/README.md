# Garage door opener remote and keypad compatibility, by opener model

Garage door opener manufacturers (LiftMaster/Chamberlain/Craftsman, Genie, Overhead Door, Linear, Stanley, Wayne Dalton and others) have shipped several generations of remote-control radio protocol on the same badge over 40 years — 8- and 9-position dip switch, then rolling-code systems each vendor names differently (Genie's Intellicode, Overhead Door's CodeDodger, Chamberlain's Billion Code, Security+ and Security+ 2.0, Linear's MegaCode) — and a replacement remote or keypad only works with the openers sharing its protocol generation, not merely its brand. No single neutral source lists this across brands: every chart found is one manufacturer's own page or one parts retailer's page for a single brand. Each record is one opener model, giving the protocol generation or dip-switch/learn-button/frequency signature that determines what will pair with it, and the visor remote, mini or keychain remote and wireless keypad part numbers the source lists for that model — each quoted verbatim from the chart row it came from. Answers 'will this remote work with my [brand] opener', 'what remote do I need for a [model] garage door opener' and 'what keypad fits a 1994 opener'.
