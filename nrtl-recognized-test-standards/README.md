# Which OSHA-recognized labs (NRTLs) can certify to a given test standard

The inverted view of OSHA's Nationally Recognized Testing Laboratory program: for each test standard, every NRTL currently recognized to certify products to it. Answers 'which NRTLs can certify to UL 508A', 'can anyone other than UL list to UL 1741', 'is my lab's mark acceptable to OSHA for this product', and 'who else could quote this job'. OSHA publishes the recognition one laboratory at a time — twenty separate pages, each a long table of that lab's standards — and its own list-of-standards page says so in as many words: 'See individual NRTL informational web pages to determine which of these standards fall within an NRTL's scope of recognition.' So the question a manufacturer actually has (who may certify my product, and therefore who can I ask for a price) requires opening and searching twenty pages, and nobody publishes the answer.

**4,329 records.** Canonical, always-current version: [https://referencesource.org/nrtl-recognized-test-standards/](https://referencesource.org/nrtl-recognized-test-standards/)
