# Minimum marriage age and exceptions by state

What is the youngest age someone can legally marry in this state, and what exceptions exist? Sixteen states and DC set an absolute minimum of 18 with no exceptions. The remaining states allow marriage below 18 through some combination of parental consent, judicial approval, emancipation, or pregnancy exceptions, with age floors ranging from 15 to 17 -- and a handful of states set no statutory age floor at all. This area is changing fast: Oklahoma eliminated its no-floor status in May 2026, Oregon's 18-minimum ban took effect in 2026, and California AB 1267 is pending for the 2026 session. The best existing compilation (Tahirih Justice Center, September 2025) is already stale on these changes and is a PDF. One record per state, each quoting the statutory text verbatim -- taken from the state's own code where the compilation is stale, and otherwise from the compilation's reproduction of that text.
