# Commercial refrigeration controller alarm code lookup by brand

What the alarm or fault code shown on a walk-in cooler/freezer digital temperature controller means, taken from each manufacturer's own manual. A restaurant or grocery refrigeration tech reads a short code off a Danfoss, Carel, or Dixell controller display and has to know which brand's board it is before the code means anything -- 'E03' is a digital-input alarm on a Carel IR33 and something else entirely on a different maker's board. Each record is one alarm/fault code from one manufacturer's controller: the code exactly as the display shows it, what it signals, and (where the manual states it) its effect on the outputs or its cause. A web search for 'walk-in cooler controller error codes' turns up only single-brand troubleshooting pages -- no cross-brand comparison exists, because each manufacturer publishes only its own controller's manual.
