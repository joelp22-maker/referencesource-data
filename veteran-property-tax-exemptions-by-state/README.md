# State Property Tax Exemptions for Disabled Veterans — Exemption Amounts, Disability Rating Thresholds, and Eligibility Rules

How much property tax does a disabled veteran owe in each state? All 50 states offer some form of property tax exemption for veterans with service-connected disabilities, but the exemption amount, qualifying disability rating, home value caps, and surviving spouse provisions vary enormously. This dataset records each state's exemption type, dollar amounts or percentage thresholds by disability rating level, home value limits, surviving spouse eligibility, annual adjustment mechanism, and the specific statutory citation.

**Licence position for this dataset.** Facts from state statutes; statutory text is government work and the facts in it are not copyrightable (Feist, 1991). Each record quotes a short attributed excerpt and links back to the page it was read from. Citation note, checked 2026-10-14: The Georgia row is cited to law.justia.com rather than to an official state host, because Georgia does not publish its code anywhere a single section can be fetched at a stable URL — Georgia's own free O.C.G.A., which the General Assembly contracts LexisNexis to publish, is a JavaScript application at advance.lexis.com that serves no statutory text to a fetch. That mirror now sits behind a Cloudflare challenge and returns 403 to everyone, an invented-slug control included, so these rows cannot at present be re-checked against the page they cite. The values were read from those pages when the records were harvested and nothing here has changed them; what is missing is any ongoing check that they are still current.
