# Dam safety hazard classification, inspection frequency, and owner obligations by US state

State-by-state comparison of dam safety programs: hazard classification systems, inspection frequencies, who must inspect, and dam owner obligations. Each record is one (state, hazard class) pair with the classification name, criteria for that class, required inspection interval, inspector qualifications, and whether inspections are mandatory or voluntary. Covers the ~91,000 non-federal dams in the US. Answers 'how often must my dam be inspected in [state]', 'what hazard classification is my dam', 'do I need a licensed engineer for inspections in [state]', and 'what are the penalties for non-compliance'. The ASDSO published a 50-state summary in 2020 as a PDF; it is now 6 years stale and not structured for search. This asset maintains the current state of each program from each state's own dam safety statute and program pages.
