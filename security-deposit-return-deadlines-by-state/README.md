# Security deposit return deadlines by US state — the statutory clock a landlord has to return a tenant's deposit, quoted from the state statute

Every state sets a statutory deadline for a landlord to return a tenant's security deposit, or to send an itemized statement of what is being withheld, after the tenancy ends. The number differs by state (14 days in Hawaii and Nebraska, 45 in Maryland and Virginia), and so does the event that starts the clock — some states run it from termination of the tenancy, some from the day the tenant hands back possession, and some from the day the tenant supplies a forwarding address, whichever is later. That trigger is where most comparison charts are silent and where disputes actually start. Each record is one state, with the deadline exactly as the statute prints it, the clause that starts the clock, any second deadline the same section sets and the condition it applies under, and the statute citation, each backed by a verbatim quote from the state's own statute site. 31 states so far; a state is here only where its own legislature or code revisor serves the section as readable text. Answers 'how long does my landlord have to return my deposit in [state]' and 'which states give landlords the longest to return a deposit'.
