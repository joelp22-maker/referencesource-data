# State small estate affidavit and simplified probate thresholds

Dollar thresholds below which heirs can use a small estate affidavit or simplified probate procedure to transfer a decedent's property without full probate, for each US state and DC. Each record is one jurisdiction, giving the personal property threshold for the affidavit procedure, any separate real property threshold, waiting period, whether a will is required to be absent, inflation adjustment schedule, and statute citation. Answers 'what is the small estate limit in [state]' and 'can I avoid probate for a $X estate in [state]'. Thresholds range from $5,000 (some states) to $208,850 (California, inflation-adjusted triennially). Several states adjust periodically; most do not. No existing compilation cites the underlying statutes, making verification impossible.
