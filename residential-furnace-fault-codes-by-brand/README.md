# Residential gas furnace fault code lookup by brand

What the flashing-LED or displayed fault code on a residential gas furnace's integrated control board means, taken from each manufacturer's own manual. A furnace tech reads a blink pattern or a short alphanumeric code off the control board and needs the manufacturer-specific meaning before touching anything; the code alone (e.g. '13', 'A033_F') means nothing without knowing whose board it is. Codes look alike across brands and mean different things: 13 is a limit switch lockout on a Carrier 58MVP and a blower/OEM mismatch on a Trane S8V2. Each record is one fault code from one brand's control board: the code as the board displays it, and the fault the manual names beside it. The corrective procedure is not reproduced here; the linked manual has it. No single source publishes this across brands because each manufacturer's control board firmware defines its own code set independently.
