# Power tool battery platform and accessory interface compatibility

Which power tool batteries, chargers, adapters and accessory interfaces work with which tools and brands, drawn from the manufacturers' own pages: Milwaukee M18, DEWALT 20V MAX/FLEXVOLT and the DCA1820 18V adapter fit table, RYOBI 18V ONE+, Makita LXT/XGT and the ADP10 charger adapter, the Bosch-led AMPShare alliance, the Metabo-led Cordless Alliance System (CAS), the Bosch/Fein Starlock oscillating multi-tool interface, and Heller's drill-bit shank interface guide.
